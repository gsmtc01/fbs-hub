1. 총칙과 적용 범위

핀빅스 허브(이하 "서비스")는 상명대학교 재학생이 학습과 편의를 목적으로 운영하는 비영리·비공식 프로젝트로서, 상명대학교의 공식 서비스가 아닙니다. 운영자(이하 "운영자")는 「개인정보 보호법」이 정한 개인정보처리자의 의무 수준에 준하여 이 방침을 수립·공개합니다.

서비스는 회원가입, 로그인, 결제 또는 자체 서버로 전송되는 문의 양식을 두지 않으며 운영자가 관리하는 응용 서버나 이용자 데이터베이스를 운영하지 않습니다. 문의·신고는 선택적으로 GitHub Issues에서 이루어지며, 해당 공개 게시판에 작성된 정보는 제2조와 제5조에 따라 처리됩니다. 이용자가 서비스 이용 과정에서 자신의 정보가 어떻게 다루어지는지 명확히 알 수 있도록 아래 사항을 공개합니다.

관련 법령 「개인정보 보호법」 제2조제5호(개인정보처리자의 정의), 제30조(개인정보 처리방침의 수립 및 공개), 같은 법 시행령 제31조(개인정보 처리방침의 내용 및 공개방법 등)

2. 처리하는 정보의 항목

서비스 자체는 이용자의 성명, 학번, 연락처, 이메일, 로그인 정보, 결제정보, 「개인정보 보호법」 제23조의 민감정보 및 제24조의 고유식별정보를 입력받거나 운영자 서버로 수집하지 않습니다. 다만 이용자가 추가 관심 키워드에 개인정보를 직접 입력하면 그 값은 해당 이용자의 브라우저에 저장될 수 있으므로 이름, 학번, 연락처 등을 입력하지 마십시오.

저장 위치저장 항목성격

문의·신고 시 처리될 수 있는 정보

이용자가 GitHub Issues를 이용하면 GitHub 계정명과 공개 프로필, 이슈 제목·본문·작성 시각이 GitHub에서 처리되고 공개됩니다. 운영자는 공개된 이슈를 확인할 수 있습니다. 서비스는 신분증, 재학증명서, 연락처 등 비공개 소명 자료를 요구하거나 접수하지 않습니다.

관련 법령 「개인정보 보호법」 제2조제1호(개인정보의 정의), 시행령 제31조제1항제1호(처리하는 개인정보의 항목)

3. 처리 목적

제2조의 정보는 다음 목적에 한하여 이용자 기기 안에서만 사용되며, 그 밖의 목적으로 이용하지 않습니다.

  • 화면 테마, 글자 표시, 움직임 줄이기 등 표시 환경의 유지
  • 관심 게시판·전공·키워드에 따른 목록 정렬과 강조 표시
  • 즐겨찾기와 읽음 상태의 유지
  • On-Device AI 모델의 중복 다운로드 방지와 실행 상태 안내
  • 네트워크가 끊겼을 때 마지막으로 성공한 목록의 오프라인 표시
  • 이용자가 선택한 GitHub Issues 문의·신고의 확인과 처리

관련 법령 「개인정보 보호법」 제30조제1항제2호(처리 및 보유 기간)

5. 제3자 제공과 처리 위탁

운영자는 이용자의 개인정보를 제3자에게 제공하거나 그 처리를 위탁하지 않습니다. 다만 서비스가 정적 웹사이트로 배포·전송되는 과정에서 아래 사업자의 인프라를 이용하며, 이는 이용자 브라우저와 각 사업자 간의 직접 통신입니다.

사업자역할운영자의 관여
GitHub, Inc.GitHub Pages 정적 웹사이트 호스팅 및 이용자가 선택한 GitHub Issues 문의Pages 접속 로그는 GitHub이 자체 정책에 따라 처리하며 운영자는 열람할 수 없습니다. 공개 이슈의 계정명과 작성 내용은 운영자가 열람할 수 있습니다.
jsDelivr글꼴 및 Transformers.js 모듈 전송파일 전송만 이루어지며 운영자에게 전달되는 정보는 없습니다.
Hugging Face이용자가 요청한 경우에만 AI 모델 파일 전송이용자가 설정에서 다운로드를 선택하기 전에는 요청이 발생하지 않습니다.
상명대학교 및 외부 언론사이용자가 선택한 원문 페이지 제공이동 이후에는 해당 사이트의 처리방침이 적용됩니다.

관련 법령 「개인정보 보호법」 제17조(개인정보의 제공), 제26조(업무위탁에 따른 개인정보의 처리 제한), 제30조제1항제3호·제4호

6. 국외 사업자와의 통신

운영자가 개인정보를 국외로 이전하는 행위는 없습니다. 다만 제5조의 사업자는 국외에 서버를 두고 있어, 이용자가 서비스에 접속하거나 AI 모델을 내려받으면 이용자 브라우저가 국외 서버에 직접 접속하게 됩니다. 이때 IP 주소, 접속 시각, 브라우저 종류 등 통상적인 접속 정보가 해당 사업자에게 전달될 수 있으므로, 「개인정보 보호법」 제28조의8제2항의 고지 항목에 준하여 다음과 같이 안내합니다.

이전받는 자국가전달될 수 있는 항목시점과 방법이용 목적
GitHub, Inc.미국IP 주소, 접속 시각, User-Agent페이지 접속 시 HTTPS 통신웹사이트 파일 전송
jsDelivr다국적 CDN 분산IP 주소, 접속 시각, User-Agent글꼴·모듈 요청 시 HTTPS 통신정적 자산 전송
Hugging Face미국IP 주소, 접속 시각, User-Agent이용자가 모델 다운로드를 선택한 경우에만 HTTPS 통신모델 파일 전송

각 사업자의 보유 기간과 처리 방식은 해당 사업자의 개인정보 처리방침을 따릅니다. AI 모델 다운로드를 선택하지 않으면 Hugging Face와의 통신은 발생하지 않습니다.

관련 법령 「개인정보 보호법」 제28조의8(개인정보의 국외 이전), 시행령 제31조제1항제2호

7. 파기 절차와 방법

운영자는 브라우저 저장값의 서버 사본을 보관하지 않으므로 별도의 서버 파기 절차를 두지 않습니다. 이용자는 제4조 표에 기재된 기능 또는 브라우저의 사이트 데이터 삭제를 이용하여 로컬 저장값을 제거할 수 있습니다. GitHub Issues의 게시물은 GitHub의 편집·삭제 기능과 정책을 따릅니다.

관련 법령 「개인정보 보호법」 제21조(개인정보의 파기), 제30조제1항제3호의2

8. 자동 수집 장치와 거부 방법

서비스는 광고 식별자, 행태정보 수집 도구, 방문자 분석 도구, 제3자 추적 쿠키를 사용하지 않습니다. 운영자가 발급하는 쿠키도 없습니다.

서비스가 사용하는 로컬 스토리지와 Cache Storage는 이용자를 추적하기 위한 장치가 아니라 화면 설정과 오프라인 열람을 위한 저장 공간입니다. 이용자는 브라우저의 사이트 데이터 차단 설정으로 저장을 거부할 수 있으며, 이 경우 설정값이 유지되지 않고 오프라인 열람과 AI 기능이 제한될 수 있으나 공지 열람 등 기본 기능은 계속 이용할 수 있습니다. 추가 관심 키워드에는 개인정보를 입력하지 마십시오.

향후 분석 도구나 쿠키를 도입할 경우, 도입 전에 이 방침을 개정하여 제16조의 절차에 따라 공지합니다.

관련 법령 「개인정보 보호법」 제30조제1항제7호(개인정보를 자동으로 수집하는 장치의 설치·운영 및 그 거부에 관한 사항)

9. On-Device 인공지능 처리

서비스의 AI 요약은 이용자가 설정에서 직접 다운로드를 선택한 경우에만 사용할 수 있는 선택 기능이며, 생성형 인공지능 모델이 이용자 기기의 WebGPU에서 실행됩니다.

  • 입력: 현재 탭과 필터 조건에 맞는 목록 중 상위 최대 12건의 제목, 수집 단계에서 150자로 제한된 짧은 요약, 날짜, 그리고 이용자가 직접 작성한 질문. 화면에 아직 펼쳐지지 않은 항목이 포함될 수 있습니다.
  • 처리 위치: 이용자 기기 내부. 추론 입력과 생성 결과를 운영자 서버나 외부 AI API로 전송하지 않으며, 그러한 전송을 수행하는 대체 경로도 두지 않습니다.
  • 생성 결과: 기본적으로 이용자 기기에만 표시되며 운영자가 수집하거나 학습에 재사용하지 않습니다. 이용자가 공유 버튼을 선택하면 결과가 운영체제의 공유 대상 또는 클립보드로 전달됩니다.
  • 음성 재생: 이용자가 음성 버튼을 선택하면 생성 결과가 브라우저 또는 운영체제의 음성 합성 엔진에 전달됩니다. 음성 엔진의 로컬·네트워크 처리 여부는 이용 환경과 선택된 음성에 따라 달라질 수 있습니다.
  • 네트워크 연결: 최초 모델 다운로드에는 네트워크가 필요합니다. 이후에는 브라우저 캐시를 우선 사용하지만 라이브러리 또는 모델 캐시의 확인·갱신 과정에서 jsDelivr나 Hugging Face로 요청이 발생할 수 있습니다(제6조 참조).

서비스의 AI 기능은 이용자의 개인정보를 처리하여 이용자의 권리·의무에 영향을 미치는 결정을 하지 않으므로, 「개인정보 보호법」 제37조의2에 따른 자동화된 결정에 해당하지 않습니다. 또한 「인공지능 발전과 신뢰 기반 조성 등에 관한 기본법」 제2조제4호 각 목의 어느 영역에도 사용되지 않아 고영향 인공지능에 해당하지 않습니다. AI 기능의 고지·표시에 관한 사항은 이용약관 제8조에서 정합니다.

관련 법령 「개인정보 보호법」 제37조의2(자동화된 결정에 대한 정보주체의 권리 등), 「인공지능 발전과 신뢰 기반 조성 등에 관한 기본법」 제2조제4호·제5호, 제31조(인공지능 투명성 확보 의무)

10. 연락처 검색 기능

연락처 검색은 이용자가 입력한 검색 범위(이름·소속·업무)와 검색어를 상명대학교의 공식 검색 페이지로 GET 방식으로 직접 전달하는 기능입니다. 운영자는 검색어를 서버에 기록하거나 브라우저 저장소에 보관하지 않으며, 검색 결과를 중계하거나 가공하지 않습니다.

GET 방식의 특성상 검색어가 상명대학교 결과 페이지의 주소에 포함되어 이용자 브라우저의 방문 기록과 해당 대학 시스템의 접속 기록에 남을 수 있습니다. 검색 결과로 표시되는 교직원 정보는 상명대학교가 공개·관리하는 정보이며 그 처리 책임은 상명대학교에 있습니다. 서비스는 전화번호를 이용한 역방향 검색을 제공하지 않습니다.

11. 공개 데이터에 포함될 수 있는 타인의 정보

서비스가 표시하는 공지 목록은 상명대학교 등이 이미 공개한 게시판의 목록 메타데이터입니다. 운영자는 작성자 필드에 포함된 개인 실명이 공개 데이터에 남지 않도록 수집·내보내기 단계에서 조직명만 허용하며, 게시물 본문과 첨부파일은 수집·저장·미러링하지 않습니다. 배포 전 검증은 공개 금지 필드, 작성자 조직명 형식, 이메일 주소, 휴대전화 번호 및 주민등록번호 형태를 자동 점검합니다. 자동 검증만으로 모든 개인정보를 판별할 수는 없으므로 오류 신고 절차를 함께 운영합니다.

그럼에도 특정 항목에 자신 또는 타인의 개인정보가 포함되었다고 판단되는 경우, 문의 · 신고 페이지의 절차에 따라 삭제를 요청할 수 있으며 운영자는 이를 확인 후 지체 없이 조치합니다.

관련 법령 「개인정보 보호법」 제3조(개인정보 보호 원칙), 제36조(개인정보의 정정·삭제), 「정보통신망 이용촉진 및 정보보호 등에 관한 법률」 제44조의2(정보의 삭제요청 등)

12. 정보주체의 권리와 행사 방법

이용자는 자신의 정보에 관하여 다음 권리를 행사할 수 있습니다.

  • 브라우저에 저장된 값: 서비스가 저장하는 값은 모두 이용자 기기 안에 있으므로, 이용자는 브라우저 개발자 도구나 사이트 데이터 설정을 통해 언제든지 직접 열람·정정·삭제할 수 있습니다. 운영자의 승인이나 별도 신청이 필요하지 않습니다.
  • 공개 데이터에 포함된 정보: 제11조에 따라 삭제 또는 정정을 요청할 수 있습니다.
  • 법정대리인: 만 14세 미만 아동의 법정대리인은 아동을 대신하여 위 권리를 행사할 수 있습니다. 다만 서비스는 연령 정보를 수집하지 않으며 아동을 대상으로 하지 않습니다.
  • 대리인: 이용자는 위임장을 갖춘 대리인을 통하여 권리를 행사할 수 있습니다.

운영자는 권리 행사를 이유로 이용자에게 어떠한 불이익도 주지 않습니다. 요청 접수 후 처리 절차와 기한은 문의 · 신고 페이지에서 확인할 수 있습니다.

관련 법령 「개인정보 보호법」 제4조(정보주체의 권리), 제35조(개인정보의 열람), 제36조(개인정보의 정정·삭제), 제37조(개인정보의 처리정지 등), 제38조(권리행사의 방법 및 절차)

13. 안전성 확보 조치

운영자는 이용자 정보의 안전을 위하여 다음 조치를 적용합니다.

  • 수집 자체의 최소화: 서버와 데이터베이스를 운영하지 않아 유출 대상이 되는 개인정보 보관본을 만들지 않습니다.
  • 인증정보 미취급: 학번, 비밀번호, 세션 쿠키, API 키를 입력받거나 저장하거나 중계하는 기능을 두지 않습니다.
  • 전송 구간 암호화: HTTPS로 제공하며, 외부 링크는 http·https만 허용하고 새 창 링크에 rel="noopener noreferrer"를 적용합니다.
  • 출력값 검증: 수집 데이터, 이용자 입력, AI 생성 결과를 화면에 표시하기 전에 이스케이프하거나 허용된 서식만 안전하게 렌더링합니다.
  • 배포 전 자동 검증: 공개 데이터의 스키마, 공개 금지 필드, 작성자 형식과 주요 고위험 식별자 패턴을 점검하며, 검증에 실패하면 배포하지 않습니다.
  • 공개 범위 관리: 수집용 데이터베이스와 수집 코드는 공개 배포 산출물에서 제외합니다.

관련 법령 「개인정보 보호법」 제29조(안전조치의무), 시행령 제30조(개인정보의 안전성 확보 조치), 제31조제1항제3호
