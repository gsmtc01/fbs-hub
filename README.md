# 핀빅스 허브

상명대학교의 공지, 채용·홍보, 학사일정, 학식, 웹진과 연락처 검색을 한 화면에서 이용할 수 있도록 정리한 비공식 학생 프로젝트입니다.

핀빅스는 핀테크전공, 빅데이터융합전공, 스마트생산전공을 함께 가리키는 명칭입니다. 이 서비스는 상명대학교가 운영하는 공식 웹사이트가 아니며, 학사 행정과 게시물 원문에 관한 최종 확인은 반드시 상명대학교의 공식 페이지에서 해야 합니다.

## 서비스 한눈에 보기

| 구분 | 제공 기능 |
|---|---|
| 공지사항 | 상명대학교, 융합공과대학, 핀빅스 공지를 통합해 검색하고 기간과 출처로 필터링 |
| 채용·홍보 | 핀빅스 관련 채용, 대외활동과 홍보 게시물 확인 |
| 학사일정 | 학사일정, 행사일정과 전공일정을 날짜순으로 확인 |
| 학식 | 주간을 선택해 월요일부터 금요일까지 식단을 식사 구분과 코너별로 확인 |
| 웹진 | 상명투데이, 뉴스레터, 상명피플과 언론 속 상명 확인 |
| 연락처 검색 | 이름, 소속 또는 업무를 상명대학교 공식 연락처 검색 페이지로 직접 전달 |
| 개인화 | 관심 출처와 키워드, 즐겨찾기, 읽음 상태, 새 공지 보기 |
| On-Device AI | 현재 필터 결과의 요약과 후속 질문 답변을 브라우저의 WebGPU에서 생성 |
| 오프라인 이용 | 마지막으로 정상 수신한 공지 목록과 앱 화면을 브라우저 캐시에서 제공 |

회원가입, 로그인, 결제와 광고는 없습니다. 공지 제목을 선택하면 핀빅스 허브 안에서 본문을 복제해 보여 주는 대신 상명대학교 또는 외부 원저작자의 원문 페이지가 열립니다.

## 이용 방법

1. 상단 또는 메뉴에서 원하는 탭을 선택합니다.
2. 공지사항, 채용·홍보와 웹진에서는 제목이나 짧은 요약을 검색할 수 있습니다.
3. 출처, 기간, 관심 항목, 즐겨찾기 또는 새 공지 필터로 목록을 좁힐 수 있습니다.
4. 공지 제목을 선택하여 원문에서 세부 내용, 첨부파일과 최신 수정 사항을 확인합니다.
5. 자주 확인할 항목은 별표 버튼으로 즐겨찾기에 저장합니다.
6. 테마, 한 화면에 표시할 항목 수, 관심 전공과 주요 키워드는 설정에서 변경합니다.

즐겨찾기, 읽음 상태와 개인화 설정은 현재 브라우저의 로컬 스토리지에 저장됩니다. 다른 브라우저나 기기와 동기화되지 않으며, 브라우저의 사이트 데이터를 삭제하면 함께 제거됩니다.

| `calendar` | 학사일정 및 전공일정 | 학사, 행사와 전공 일정 |

수집 대상은 공개 목록에 표시된 제목, 짧은 요약, 부서명, 날짜, 조회 수, 분류와 원문 URL입니다. 게시물 본문 전문, 첨부파일, 담당자 개인 실명과 로그인이 필요한 정보는 수집하거나 미러링하지 않습니다.

공개 데이터는 한국 시간 기준 매일 오전 6시 10분과 오후 3시 10분에 갱신을 시도합니다. 11개 출처 중 하나라도 수집에 실패하면 불완전한 결과를 새 데이터처럼 배포하지 않습니다. 출처 페이지의 변경, 서버 장애 또는 네트워크 상태에 따라 갱신이 지연될 수 있습니다.

학식 수집기는 조식, 중식, 석식과 간식 구분을 모두 확인합니다. 조식은 학기 중 상명대학교의 ‘천원의 아침밥’ 사업이 운영되는 주에만 표시됩니다. 화면의 주간 선택에서 현재 식단과 보존된 과거 주간 식단을 확인할 수 있습니다.

학술정보관은 `robots.txt` 정책에 따라 수집 대상에서 제외합니다. 기숙사, IT 매뉴얼, 학생회 공지, 자료실, Q&A와 카드뉴스 등 현재 등록되지 않은 페이지는 서비스에 나타나지 않을 수 있습니다.

## On-Device AI

AI 기능은 기본적으로 비활성화되어 있습니다. 설정에서 이용자가 직접 모델 다운로드를 선택한 경우에만 `onnx-community/gemma-4-E2B-it-ONNX` 모델을 내려받아 실행합니다.

### 실행 조건

- ONNX Runtime Web의 WebGPU 백엔드가 공식 지원되는 최신 Chrome 또는 Edge와 호환 그래픽 장치가 필요합니다.
- Safari 26 및 iOS 26 이상에서는 WebGPU와 브라우저 캐시가 감지될 때 다운로드를 실험적으로 시도할 수 있습니다. 현재 ONNX Runtime Web 공식 지원표에는 Safari와 iOS의 WebGPU 실행이 지원 대상으로 표시되지 않아 모델 초기화가 실패할 수 있습니다.
- iOS의 Safari, Chrome, Edge에서 WebGPU가 감지되지 않거나 모델 실행이 실패해도 공지 검색, 필터와 원문 열람은 그대로 이용할 수 있습니다. 현재 Gemma 4 모델은 메모리와 성능 제약 때문에 WebAssembly 대체 실행을 제공하지 않습니다.
- 최초 다운로드에는 인터넷 연결과 수 GB의 여유 저장 공간이 필요할 수 있습니다.
- 이후에는 브라우저 캐시를 우선 사용하지만 라이브러리 또는 모델 확인 과정에서 네트워크 요청이 다시 발생할 수 있습니다.
- 모델 캐시를 삭제하면 다시 내려받아야 합니다.

### 처리 방식

- 현재 조건으로 필터링된 항목에서 출처 다양성 또는 질문 관련도를 기준으로 최대 12건을 선별하고 제목, 짧은 발췌, 날짜, 게시판과 부서 정보를 입력 근거로 사용합니다.
- 추론 입력과 생성 결과를 운영자 서버나 외부 AI API로 전송하지 않습니다.
- 음성 읽기를 실행하면 결과가 브라우저 또는 운영체제의 음성 합성 기능으로 전달될 수 있습니다.
- 공유를 선택하면 결과가 운영체제의 공유 대상 또는 클립보드로 전달됩니다.

생성형 AI의 요약과 답변은 원문을 잘못 해석하거나 사실과 다른 내용을 만들 수 있습니다. 수강신청, 장학금, 취업, 등록과 일정처럼 중요한 판단에는 AI 결과를 사용하지 말고 반드시 원문을 확인하십시오.

Gemma 4 E2B와 현재 사용하는 ONNX 변환본은 Apache License 2.0으로 제공됩니다. 세부 고지는 [라이선스 문서](./pages/licenses.html)에서 확인할 수 있습니다.

## 개인정보와 외부 통신

핀빅스 허브는 이용자 계정을 만들거나 운영자 애플리케이션 서버에 개인별 이용 기록을 저장하지 않습니다. 자체 분석 도구와 광고 추적기도 사용하지 않습니다.

다만 서비스 이용 과정에서 다음 외부 통신이 발생할 수 있습니다.

| 대상 | 발생 시점 | 전달될 수 있는 정보 |
|---|---|---|
| GitHub Pages | 사이트 접속 | GitHub가 자체 정책에 따라 처리하는 일반 접속 정보 |
| jsDelivr | 화면 글꼴과 AI 런타임 로드 | 일반적인 HTTP 요청 정보 |
| Hugging Face | 이용자가 AI 모델 다운로드를 선택한 경우 | 모델 파일 요청에 필요한 일반적인 HTTP 요청 정보 |
| 상명대학교 | 원문, 연락처 검색 또는 공식 페이지를 연 경우 | 해당 페이지 접속 정보와 이용자가 입력한 연락처 검색어 |
| GitHub Issues | 문의나 신고를 직접 등록한 경우 | GitHub 계정명과 이용자가 작성한 공개 이슈 내용 |

관심 키워드에는 이름, 학번, 전화번호와 같은 개인정보를 입력하지 마십시오. GitHub Issues는 공개 게시판이므로 신분증, 증명서, 연락처, 실제 개인정보 값과 비공개 자료를 게시해서는 안 됩니다.

자세한 내용은 [개인정보 처리방침](./pages/privacy.html)과 [문의·신고 안내](./pages/support.html)에서 확인할 수 있습니다.

## 정확성과 서비스 한계

- 핀빅스 허브는 대학의 공식 공지 시스템이 아닙니다.
- 목록 정보는 원문 페이지보다 늦게 반영되거나 일부 누락될 수 있습니다.
- 게시물이 수정 또는 삭제된 경우 기존 링크가 열리지 않을 수 있습니다.
- 제목, 날짜, 분류와 일정이 원문과 다르면 원문 정보가 우선합니다.
- 서비스의 장애나 데이터 지연을 이유로 학사상 기한이 연장되거나 공식 구제가 제공되지 않습니다.
- 연락처 검색 결과와 학사 행정 문의는 상명대학교 담당 부서에서 확인해야 합니다.

데이터 오류, 깨진 링크, 접근성 문제와 권리침해 가능성은 [문의·신고 페이지](./pages/support.html)의 공개 GitHub Issues 양식으로 알려 주십시오.

## 접근성과 브라우저 지원

서비스는 키보드 조작, 화면 낭독기용 레이블과 상태 알림, 라이트·다크·시스템 테마, 움직임 줄이기 설정과 반응형 화면을 지원합니다.

공지 열람과 검색은 일반적인 최신 브라우저에서 사용할 수 있습니다. On-Device AI는 최신 Chrome 또는 Edge의 WebGPU 백엔드를 공식 지원 환경으로 삼습니다. Safari 26 및 iOS 26 이상은 WebGPU가 감지되는 경우 실험적으로 시도할 수 있으나, 현재 실행 스택의 공식 지원 범위와 기기 메모리 제한 때문에 동작을 보장하지 않습니다. 지원 환경에서도 브라우저와 그래픽 드라이버에 따라 모델 실행 속도와 안정성이 달라질 수 있습니다.

## 로컬에서 실행하기

일반적인 화면 확인에는 별도의 JavaScript 빌드 도구가 필요하지 않습니다.

```bash
python3 export_static.py
python3 server.py
```

브라우저에서 `http://localhost:8000`을 엽니다. `file://` 방식으로 `index.html`을 직접 열면 브라우저 보안 정책 때문에 JSON, ES 모듈과 서비스 워커가 정상적으로 동작하지 않습니다.

## 데이터 갱신과 검증

수집기를 실행하려면 Python 의존성을 먼저 설치합니다.

```bash
python3 -m pip install --requirement requirements.txt
python3 ingest.py --limit 30
python3 export_static.py
python3 validate_data.py
```

특정 주의 학식만 보충할 때에는 수집 기준일과 식사 구분 코드를 지정할 수 있습니다. 예를 들어 2026년 6월 조식 두 주를 보충하는 명령은 다음과 같습니다.

```bash
python3 ingest.py --board restaurant \
  --meal-date 2026-06-01 \
  --meal-date 2026-06-08 \
  --meal-category B
```

전체 배포 전 검증 명령은 다음과 같습니다.

```bash
python3 -m unittest discover -s tests
node --test tests/test_local_llm.mjs
python3 validate_data.py
python3 build_site.py
python3 verify_deploy.py
```

검증 과정은 파서 동작, 식단 구조, 공개 JSON 스키마, 개인정보 형태, 작성자 조직명, AI 프롬프트, 내부 링크, 앵커, 새 창 링크의 보안 속성과 배포 파일 구성을 확인합니다.

## GitHub Pages 배포

저장소에는 다음 자동화가 포함되어 있습니다.

- `Deploy GitHub Pages`: 테스트, 공개 데이터 내보내기, 정책 검증, 배포 산출물 생성과 Pages 배포를 수행합니다.
- `Update notice data`: 한국 시간 오전 6시 10분과 오후 3시 10분에 공개 목록을 수집하고 변경된 데이터베이스와 JSON을 커밋합니다.

배포 절차는 다음과 같습니다.

1. 이 프로젝트를 GitHub 저장소의 `main` 브랜치에 올립니다.
2. 저장소의 `Settings > Pages > Build and deployment`에서 `GitHub Actions`를 선택합니다.
3. 저장소 정책에서 GitHub Actions가 데이터 갱신 커밋을 푸시할 수 있도록 `contents: write` 권한을 허용합니다.
4. `Deploy GitHub Pages` 워크플로를 수동으로 실행하거나 `main` 브랜치에 변경 사항을 푸시합니다.
5. 배포 완료 후 메인 화면, 법적 고지 페이지, 원문 링크와 GitHub Issues 연결을 확인합니다.

`build_site.py`는 공개에 필요한 파일만 `dist`에 복사합니다. 데이터베이스, 수집기, 테스트, 디자인 참고 파일과 개발용 서버는 배포 산출물에 포함하지 않습니다.

GitHub Pages 기본 주소에서는 저장소와 이슈 주소를 자동으로 추론합니다. 별도 도메인을 사용하는 경우 [app.js](./app.js)의 `CONFIG.repositoryUrl`에 실제 GitHub 저장소 주소를 지정해야 문의·신고 링크를 정확하게 만들 수 있습니다.

## 프로젝트 구성

| 경로 | 역할 |
|---|---|
| `index.html`, `styles.css`, `app.js` | 메인 화면과 사용자 기능 |
| `share-utils.js` | 외부 공유 본문과 원문 URL의 호환성 있는 조합 |
| `local-llm.js` | WebGPU 기반 On-Device AI 실행 |
| `collector.py`, `ingest.py` | 공개 목록 수집과 SQLite 적재 |
| `export_static.py` | 공개 가능한 필드만 JSON으로 내보내기 |
| `validate_data.py` | 공개 데이터 정책 검증 |
| `build_site.py` | GitHub Pages 배포 산출물 생성 |
| `verify_deploy.py` | 배포 파일, 링크와 공개 정책 최종 검증 |
| `pages/` | 개인정보, 약관, 저작권, 라이선스와 지원 문서 |
| `.github/workflows/` | 자동 데이터 갱신과 Pages 배포 워크플로 |

수집과 구현 정책은 [AGENTS.md](./AGENTS.md)를 기준으로 유지합니다.
